    Setup guide: from zero to a working connection
    1. Install Ollama from ollama.com/download (Windows, macOS, Linux). No graphics card needed.
    2. Make sure it is running. On Windows and macOS the Ollama app sits by the clock / in the menu bar. On Linux run ollama serve. Opening http://localhost:11434 in a new tab should show "Ollama is running".
    3. Download a model. In a terminal: ollama pull deepseek-r1:1.5b (1.1 GB, thinks before answering) or ollama pull gemma3:1b (0.8 GB, fast).
    4. Enter the settings above and press Save settings. They are stored in this browser only (how localStorage works).
    5. Run the checks. If "Ollama reachable" fails with a CORS message, either allow it (instructions) or start the Go server and choose "connect through the Go API server".
    6. Optional — the Go server. Install Go from go.dev, then in the kit's server folder run go run . and open http://localhost:8080. It saves every run and exports Markdown / PDF.
