What you will learn

The kit is built around the questions a team must answer before an AI application or agent goes live. Each one maps to a concrete test you will run yourself.

Questions people ask

I have never run an AI model. Can I do this?

Yes. The tutorial starts from "what is a language model" and uses a simulated model that needs no setup. The wizard and tool checkers get you through the real installation, and the Zoom session is there if you get stuck.

Does it work on my own data instead of the grocery store?

Yes. The grocery store is a teaching example. Replace the text file and the questions file with your own document and questions; the scorer, runner, lab and reports work unchanged. The checklist explains how to write good questions for chatbots, document-search apps and agents.

Which models can I test?

Anything Ollama can run: deepseek-r1, llama 3.2, gemma 3, qwen 3, mistral, phi and hundreds more, including larger ones if you have the memory. The runner only uses Ollama's standard API, so any server that speaks it also works.

Is there a subscription? Does it phone home?

No subscription. The license key is checked on your computer against a public key; nothing is sent anywhere. The software keeps working forever; the key's date only controls how long you get updates and support.

What does "trial mode" mean?

Without a key, the kit runs the 6 starter questions in the baseline prompt style and watermarks exports — enough to confirm it works on your machine. The key unlocks all 42 questions, all 8 prompt styles, repeats and clean reports.
