# Go API server (optional)

A single-binary helper for the web pages. No external Go modules.

```
cd server
go run .                 # listens on :8080; expects Ollama at http://localhost:11434
go build -o grocery-server . && ./grocery-server -addr :8080 -ollama http://localhost:11434 -web ../web -data ./data
```

Then open http://localhost:8080 (tutorial) or http://localhost:8080/lab.html (live lab).
When the lab is opened through this server it automatically routes model calls through it,
so the browser never talks to Ollama directly and CORS is never an issue.

| Endpoint | What it does |
|---|---|
| `GET /` | serves the `web/` folder |
| `GET /api/health` | server version, Ollama reachability, number of saved runs |
| `ANY /api/ollama/*` | forwards to Ollama (e.g. `/api/ollama/api/chat`, `/api/ollama/api/tags`) |
| `GET /api/runs` | list saved runs |
| `POST /api/runs` | save a run (JSON in the lab's format; returns `{id}`) |
| `GET /api/runs/{id}` | the run as JSON |
| `DELETE /api/runs/{id}` | remove it |
| `GET /api/runs/{id}/report.md` | Markdown report |
| `GET /api/runs/{id}/report.html` | printable HTML report (print → save as PDF) |
| `GET /api/runs/{id}/report.pdf` | PDF report (text, generated by the server) |
| `GET /api/runs/{id}/results.csv` | one row per answer |
| `GET /api/runs/{id}/run.json` | download the run file |

Runs are stored as `data/runs/<id>.json`. Install Go from https://go.dev/dl/ (1.21 or newer).
